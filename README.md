# TFSBD Engineering Calculator Suite

Free Windows desktop app by Trade Finance Solution Bangladesh (TFSBD): general, RF, BLDC motor and MAK ECO Boat engineering calculators. Windows 64-bit.

## Download
Go to **Releases** (right sidebar) and download:
- **Setup** (installer, recommended)
- **Portable** (no installation)

## Windows warning
The app is not yet code-signed, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**, only if you downloaded it from this page or tfsbd.com.
